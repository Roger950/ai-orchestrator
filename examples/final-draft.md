# Windows 个人项目备份方案（演示）

本方案来自三个明确标注的模拟回答及 Codex 审核，用于演示本工具的文件交接。

1. 先确认可用存储与空间。若已有独立磁盘，优先使用；若只有同一磁盘，明确接受设备损坏风险。
2. 每周把项目复制到按日期命名的目录，保留至少两期，操作前核对源路径与目标路径。
3. 先用无关测试文件演练：从副本恢复到临时目录并对比内容，避免覆盖工作文件。
4. 记录复制与恢复验证的结果、空间及耗时，再判断每周十分钟能否满足需求。

不使用会传播删除的镜像作为唯一副本。备份间新增内容仍可能丢失。
此处没有执行任何系统备份、删除、联网核验；Windows 自带备份功能的可用性尚待现场确认。
