# Public snapshot boundary

Included: reusable Python source, synthetic tests and fixtures, synthetic examples, generic instructions and development progress.

Excluded: all personal runtime policy files; task descriptions and results; chat/session URLs and identifiers; account names, subscription facts and email addresses; raw snapshots; browser captures; local logs; credentials and authentication settings; machine-specific user directories; original repository history.

The public default policy uses unknown subscriptions and has no account evidence or locks. Model names are illustrative candidates. Account-specific policy is generated locally and ignored by Git.

Use an explicit file allowlist for future exports. Never force-add ignored runtime data. Review changes before publishing. A public GitHub repository necessarily displays its owner; this document does not promise anonymous repository ownership.
